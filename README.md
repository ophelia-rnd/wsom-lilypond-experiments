# Revised Lilypond experiments for WSOM+

This repository is a refined version of the Lilypond experiments submitted for the WSOM+ conference.
It includes the utilization of `SomRepresentation`, the new `lilypond` library, along with `Bianor`.

The experiments are found in the [`experiments`](experiments/) folder (with individual figures located in [`experiments/_exports`](experiments/_exports/)), while a dedicated [Bianor instance](https://bianor-lilypond-experiments.onrender.com/) provides an interactive way to inspect representations.
